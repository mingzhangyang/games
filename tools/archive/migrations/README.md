# Archived migrations

These files are historical one-off migrations that have already been applied to the repository.
They are retained for provenance and for understanding past transformations, not as supported
day-to-day commands. Current architecture changes belong in registry generation, platform modules,
or tests rather than another repository-wide mutation script.

If an old migration must be replayed, use the commit where it originally lived so its relative
paths and assumptions match that repository state.
