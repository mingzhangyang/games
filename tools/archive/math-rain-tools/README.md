# Archived Math Rain tools

These files are retained for historical reference only. They came from an older
Math Rain question-bank workflow and are not part of the current build or test
pipeline.

The old scripts reference `expression-generator.js`, which is no longer present
in this tool directory, so they should not be treated as supported commands.
Current Math Rain runtime code lives under `js/math-rain/`; new generators
should be added under `tools/generators/` with explicit tests before being
wired into package scripts.
