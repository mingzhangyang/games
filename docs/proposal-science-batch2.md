## 1. 为什么是这一组

站内 16 款中科学向已有 6 款：弹道（街机投篮）、绳索摆（垂丝引露）、轨道（引力弹弓）、几何光学（折光）、电路（电路谜题）、化学价键（键合工坊）。**物理的波动学、热力学，化学的原子结构、溶液结晶仍是空白**——而这四块恰好都是「现象本身最好看」的领域：扩散的波纹、干涉条纹、双色粒子云、焰色谱线、晶体生长，全是 Canvas 程序绘制（零贴图）的甜点区。

沿用键合工坊提案的三条铁律：

1. **不做问答 quiz**——把知识做成可触摸的机制，不做「做题 App」；
2. **判定可验证**——每款都有确定性判定 + 离线校验器 + par 求解（solveBest 模式）；
3. **反馈诚实**——错误反馈附带规则本身，不扣分、不嘲讽、无倒计时压迫。

## 3. 各概念详案

### 3.1 回声洞窟 Echo Cave — 物理·声波 ★首推

**一句话**：洞穴全黑，看不见岩壁——点一下，一圈声波荡开，回来的是光。

- **学科落点**：波速 v=fλ、回声测距 2d=vt、反射与吸收、多普勒效应、声波衰减。
- **核心循环**：发脉冲 → 波前扩散、遇壁反射 → 回波按传播延迟描出岩壁发光轮廓（渐隐）→ 用有限脉冲摸清地形，收集声晶、抵达出口。
- **进阶机制**：①吸音苔藓（吸收墙，回波微弱）②多普勒晶簇（移动发声时波色偏移，靠色环定位）③双源干涉照明（两脉冲叠加相长，照亮远端暗区）④潮汐墙（动态地形，要求预测回波时序）。
- **判定与验证**：波前传播在网格上就是 BFS——对每关跑可达性 + 覆盖规划，**par（最少脉冲数）精确可解**，站内第一个解算器 100% 命中的物理游戏。
- **视觉**：整站最黑的一款（与折光「最亮」成对）：纯黑洞穴、青色波前圈、回波白线余辉 3s；声晶呼吸光、出口低频嗡鸣光晕。
- **音效是主角**：回波按距离映射音高与延迟（真·声呐），站内第一次「听声辨位」。
- **计分**：每关脉冲数（asc），20 洞穴 + 每日 5 穴，高尔夫口径。
- **风险与规避**：强光环境下全黑画面可读性 → 回波轮廓余辉保留 3s；移动端性能 → 波前圈离屏描边缓存，脉冲同屏上限 4。

### 3.2 涟漪双生 Ripple Duet — 物理·波的干涉

**一句话**：两根手指、两个波源——把风暴的海面抹平，把熄灭的浮标点亮。

- **学科落点**：叠加原理、相位与波程差、相长相消、驻波（进阶：双缝）。
- **核心循环**：关卡给一片波动海面 + 目标（A 点振幅归零=消波 / B 点振幅最大=点亮浮标 / 航线全程平静）→ 拖动波源位置、调频率与相位 → 实时干涉图样 → 达标后图样定格，成为一幅「波的艺术品」（每关独一无二的纹理）。
- **机制元素**：可控波源（n=1~3，拖位置/调频率/调相位）、风暴源（不可控，必须对冲）、防波堤（反射体）、浮标（目标探测器）、平静航道（线状判定区）。
- **判定与验证**：波场解析（正弦叠加），目标点复振幅精确计算，判定零模糊；par 用数值搜索（源位置网格离散 + 相位扫描）。
- **视觉**：干涉条纹本身就是艺术品；过关时条纹「结晶」定格。波峰红/波谷蓝双色编码，降低抽象门槛。
- **计分**：拖动+调节次数（asc）。
- **风险与规避**：全屏波场渲染性能 → 半分辨率缓冲 + 解析着色；概念抽象 → 前 3 关只做「对消」一个概念。

### 3.3 麦克斯韦妖 Maxwell's Demon — 物理·热与熵

**一句话**：你是那只小妖，守着中间的小门——左边要热、右边要冷，但每开一次门都要付账。

- **学科落点**：温度=分子平均动能、熵与热力学第二定律、信息与能量的代价（佯谬→兰道尔原理，知识卡提及，不进机制）、（现象层）扩散。
- **核心循环**：盒中约 40 个分子无规运动，快（红）慢（蓝）；玩家控制隔板小门开合，放行「该过」的分子把温差拉大到目标；但**每次开合 + 每次「看清分子速度」都消耗预算**——信息本身有价。
- **深度所在**：贪心（见快就放）vs 规划（等最值的），预算紧的关卡必须挑最值钱的分子放行——把「信息有价值」变成手感。
- **判定与验证**：固定物理步长 + 种子化确定性模拟，逻辑与渲染分离（站内已有先例）；关卡 = 初始分布 + 目标温差 + 预算，校验器用贪心+模拟断言「预算内可达」。
- **视觉**：双色粒子云渐变分色，温差表是一条缓缓张开的光谱带；过关瞬间左右颜色彻底分离，门缝留下一道发光细线。
- **计分**：剩余预算（asc，越小越聪明）。
- **风险与规避**：模拟型判定公平性 → 固定步长+逻辑渲染分离；概念门槛高 → 温度计用颜色不用数值，数值留给知识卡。

### 3.4 焰语 Flame Verse — 化学·原子光谱

**一句话**：往火里撒一把盐，火焰说出元素的名字——再用分光镜，读懂那句「光的指纹」。

- **学科落点**：电子跃迁与光子能量、发射光谱、焰色反应（Na 黄 / Li 红 / Cu 绿 / K 紫…）、谱线=元素指纹（光谱分析是天体物理认星星成分的真实方法）、玻尔模型。
- **核心循环**：黑幕一支火焰 + 一个「未知样品」的谱线条码 → 从盐架（NaCl / CuSO₄ / Li₂CO₃…）挑选投入 → 火焰变色、谱线实时叠加 → 调混合比例让强度比匹配 → 用自己的谱线复现目标条码，报出元素名单。
- **与键合工坊成对**：键合教「结构与连接」，焰语教「指纹与鉴定」——拼装之后是侦探。
- **判定与验证**：谱线数据全部真实硬编码（Na 589nm 双线、Cu 510/515/521nm 系…）进白名单；比对用谱线集合 + 强度比区间（主/次/痕三档），复用键合工坊 canon 规范化比对经验。
- **视觉**：黑底火焰粒子（颜色=真实焰色）+ 底部光谱条（条形码/钢琴键质感），「谱线即指纹」的视觉母题贯穿全站宣传图。
- **音效**：每条谱线映射一个音高（波长→音高单调映射），配齐样品=一段和弦——「听见光谱」。
- **计分**：投盐+调比操作数（asc）+ 星级。
- **关卡纪律（硬约束）**：全部化合物与谱线真实存在并标中文名与波长；禁止虚构谱线；强度比只做三档不做连续校准（连续量在触屏上易挫败）。
- **风险与规避**：科学准确性红线（同键合 §7）——波长表独立数据文件过校验；后期决策深度靠「多元素混合鉴定」（谱线重叠干扰）支撑。

### 3.5 晶绽 Crystal Bloom — 化学·溶液与结晶

**一句话**：在温度-时间画布上画一条曲线，晶体就照着你画的脾气生长。

- **学科落点**：溶解度曲线、饱和/过饱和、成核与生长速率、降温速率决定晶形（快=枝晶针簇，慢=粗大规则晶）、晶胞对称类（立方/八面体/针状）。
- **核心循环**：关卡给一锅热饱和液 + 目标晶形卡（如「八面体硫酸铜蓝晶」）+ 操作预算 → 玩家在温度-时间坐标上**画降温曲线**（可放晶种、可搅拌、可加杂点）→ 元胞自动机按局部过饱和度生长 → 长出的晶体与目标晶形比对。
- **深度所在**：曲线的**形状**就是策略——先陡后缓还是线性？何处放晶种？全批最「规划感」的一款（画路径解谜的变体）。
- **判定与验证**：元胞自动机规则确定性（种子化）；晶形比对按对称类 + 主轴比（复用键合工坊规范化比对思路）；校验器对每关跑规则回归，保证「曲线 X → 晶形 Y」映射稳定。
- **视觉**：晶体从晶种发出对称生长的光枝，结晶瞬间整簇点亮；过关后晶体重演一遍生长过程（回放即知识）。
- **计分**：曲线锚点数 + 辅助动作（asc）。
- **风险与规避**：元胞自动机手感调校成本高 → 先做 5 档离散温度速率的保守版验证手感，再放开自由曲线；教学准确性只讲对称类、不谈晶格常数。

## 6. 共性技术纪要（五款通用）

- 骨架复用全套：tokens/layout/more-games、bindChrome、createStatsDrawer（pauseQuiet/resumeQuiet/isRunning）、bindFrame、i18n、daily、leaderboard、safe-storage、analytics、sfx、icons；按钮一律 `ICONS.*` + `game-btn`，零 emoji。
- 计分口径：除麦克斯韦妖（剩余预算）外全部为离散操作量 asc，跨设备公平（键合/垂丝已验证该口径）；时间绝不进榜。
- 判定单一来源：规则常量与判定函数独立成 `js/<id>-rules.js`，校验器与运行时同源 import（键合 §3.3 模式）。
- 每款配 `scripts/verify-<id>-levels.mjs` + `scripts/smoke-<id>.mjs`，进 SUITE/QUICK_NAMES。
- registry 登记照键合 §5.3：改 `games.config.json` → `npm run gen` 派生 9 处；`verify-stats-drawer` AUGMENT、`verify-button-icons` TARGETS 手工表兜底记得补。
- i18n：科学名词双语全部走键（波长、元素名、温差、溶解度……），placeholder-leak 覆盖。
- 反馈诚实原则照抄键合 §2.6：错误反馈附规则、不扣分、不嘲讽、无倒计时压迫。
- resize 用 `clientWidth` 整数（垂丝引露踩过的糊屏坑）；JS 生成 class 与 CSS 选择器逐字一致（`sd-chip` 坑）。
