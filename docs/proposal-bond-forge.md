# 新游戏提案：键合工坊 Bond Forge

> 状态：**提案待拍板** · 2026-09-21
> 一句话：把原子拖进分子骨架，按真实价键规则搭出目标分子——搭对了看见它「成键发光」，搭错了看见键角弹开。
> 英文名 **Bond Forge**，中文名 **键合工坊**，id `bond-forge`，prefix `bf`。

---

## 1. 为什么是它

| 维度 | 论证 |
| --- | --- |
| 学科补位 | 全站已有物理 7 款（弹道/引力/碰撞/气动/光/电/绳索）、数学 1 款（数字雨）、语言 1 款（每日猜词）、棋类 3 款、逻辑 2 款。**化学是唯一空白学科**，与「寓教于乐」的诉求正对 |
| 玩法血统 | 拼装类玩法在站内有先例（星球合成的「合并」、俄罗斯方块的「摆放」），但**「按真实规则拼装 + 规则本身是知识」**是新的：星球的合并规则是凭空设计的，本作的规则是**真实的化学** |
| 教育正当性 | 价键、键角、官能团、同分异构、氧化态、反应配平——全部是中学到大学化学的核心概念，且**都能用「拖拽 + 吸附」表达**，不需要背公式 |
| 技术复用 | 网格吸附（五子棋/黑白棋）、拖拽（垂丝引露刚验证）、20 关 + 每日 + 榜单骨架、抽屉/顶栏/舞台预算三契约全部现成 |
| 表现力 | 「成键瞬间」有天然的视觉与听觉落点：键线从虚线变实线、电子云脉冲、和声音程。**化学生来就有美感**，这是它比抽象谜题更适合精雕的地方 |

**差异化关键**：不做「化学问答」（那是 quiz，不是游戏），做**「化学手感」**——把价键规则变成可触摸的拖拽约束，玩家在试错中内化规则。

备选概念（已否）：
- **滴定配色**（pH 指示剂变色，颜色插值好看但玩法只有「慢慢加」，无决策深度）；
- **元素合成**（质子中子拼核，本质是数值加法，与星球合成重复度过高）。

## 2. 玩法设计

### 2.1 核心循环

```
观察目标分子式（如 H₂O）
   ↓
从「原子盘」拖出原子（O、H、H）到画布
   ↓
把原子拖到彼此的「价键热区」附近 → 自动吸附成键
   ↓
键角/价态校验：合法 → 键线实化 + 电子云脉冲 + 和声音程
                非法 → 键弹开 + 红色抖动 + 提示「O 只能接 2 根键」
   ↓
所有原子成键且无悬空价 → 过关，比「用了几次拖拽 / 用了几秒」
```

**核心张力**：原子盘给的原子**数量恰好够但顺序不定**，且关卡的分子有**同分异构体**（如 C₂H₆O 可以是乙醇或二甲醚）——玩家可能搭出一个**合法但不是目标**的分子，游戏要说「这是个真分子，但不是我要的那个」，这比单纯的「错了」有教育价值得多。

### 2.2 元素表（9 种）

| 元素 | 物理/规则行为 | 视觉 | 首次出现 |
| --- | --- | --- | --- |
| 原子 atom | 可拖拽盘面实体，带 `valence`（可成键数）与 `radius` | 圆 + 元素符号 + 渐变球 | 第 1 关 |
| 价键热区 bondSlot | 原子圆周上的吸附点，数量 = 价电子数 | 悬空价时显示半透明小圆 | 第 1 关 |
| 化学键 bond | 两 slot 吸附后生成，记录 `order`（1/2/3） | 实线（单）/ 双线（双）/ 三线 | 第 1 关 |
| 孤对电子 lonePair | 不参与成键，占位并影响键角 | 两点小圆 | 第 2 关（H₂O） |
| 官能团 group | 预置的原子簇，一次拖入（-OH / -COOH / -NH₂） | 组合卡片 | 第 7 关 |
| 电荷 charge | 离子键：正负相吸，可跨距离成键 | ± 角标 + 电场线 | 第 10 关 |
| 双键/三键 order | 同一对原子间可加键，改变几何 | 线宽编码 | 第 12 关 |
| 催化剂 catalyst | 一次性道具，允许作弊式改一根键 | 星形晶格 | 第 16 关 |
| 反应釜 reactor | 关卡目标容器，按配方校验最终分子 | 圆形炉膛 | 第 1 关 |

### 2.3 计分与榜单

- **每关**：星芒 1–3（星级由「无撤销」「无催化剂」「一次成型」三条给） + 本关**拖拽次数**。
- **战役榜**（all-time，asc）：全 20 关「最佳拖拽次数」之和，20 关全部通关后才提交。**越少越好**（高尔夫口径，与垂丝引露一致）。
- **每日榜**（asc，键 `bond-forge-d<YYYYMMDD>`）：每日 5 关（`js/daily.js` UTC+8 种子，FNV-1a + mulberry32 从 20 关池抽 5 关，按 par 升序），总拖拽次数在 5 关全部完成后提交。
- 每关带**设计师 par**（目标拖拽次数），HUD 显示 `拖拽 4 / par 6` 作自我参照，不进榜。

> **为什么计「拖拽次数」而不是「时间」**：时间受设备性能与手速影响，跨设备不公平；拖拽次数是离散量与帧时序无关（垂丝引露已验证该口径），而且它**直接度量「你有没有想清楚再动手」**——正好是本作的教育目标。

### 2.4 模式

1. **闯关**：20 手工关，难度曲线按「原子数 → 价键约束 → 官能团 → 电荷 → 多重键」递进，进度存 `bf_progress`（`safe-storage`，每关 `{stars, bestDrags}`）。
2. **每日挑战**：当天 5 关，完成标记 `bf_daily_<YYYYMMDD>`。
3. **自由重玩**：已通关卡随时回放刷次数。

### 2.5 关卡设计纪律（硬约束）

关卡**手写**（化学式是知识，不该让脚本随机生成无意义的分子），但**必须逐关通过校验器**：

1. **目标分子真实存在**：每个 `target` 的分子式 + 键拓扑必须在 `MOLECULES` 白名单里，且标注中文名（如 `C₂H₅OH = 乙醇`）。校验器拒绝「凭空发明的分子」。
2. **原子盘守恒**：盘面原子的元素与数量之和 **恰好等于** 目标分子 + 允许的同分异构体所需的原子（不多不少）。多了会出现无解，少了直接不可能。
3. **同分异构体必须被显式列出**：若该分子式存在其他合法拓扑，`isomers` 字段必须列全，否则玩家搭出真分子却被判错 = 欺骗性反馈。
4. **par 可达性**：校验器用脚本模拟「最优拖拽序列」，断言 `bestDrags <= par`。par 由模拟得出，**不是手填的估计值**。
5. **至少存在一条满星路径**：无撤销 + 无催化剂 + 一次成型三条同时满足的解法必须存在。

校验器 `scripts/verify-bond-forge-levels.mjs`。

### 2.6 反馈诚实原则（教育产品的底线）

| 情形 | 必须的反馈 |
| --- | --- |
| 键合法但不是目标 | 「这是二甲醚（C₂H₆O），真实存在，但不是本题的乙醇」——**表扬其正确性，指出其不是目标** |
| 超出价态 | 「氧最多接 2 根键」——**给规则，不给嘲讽** |
| 键角不合理 | 显示理想键角（104.5°）与当前角度的对比弧线 |
| 完全无解 | 不做「不可能判定」，只提示「换个位置试试」 |

**绝不做**：扣分、倒计时压迫、失败音效刺耳、嘲讽文案。这是寓教于乐与「做题 App」的分界线。

## 3. 化学规范

> 规则常量集中在 `js/bond-forge-molecules.js` 的 `ELEMENTS` 与 `MOLECULES`，单一来源。

### 3.1 元素表

| 元素 | 符号 | 价电子 | 最大键数 | 半径(px) | 电负性 | 颜色 |
| --- | --- | --- | --- | --- | --- | --- |
| 氢 | H | 1 | 1 | 14 | 2.20 | `#e8ecff` |
| 碳 | C | 4 | 4 | 22 | 2.55 | `#4a5568` |
| 氮 | N | 5 | 3 | 20 | 3.04 | `#5b8dee` |
| 氧 | O | 6 | 2 | 19 | 3.44 | `#ff6b7a` |
| 硫 | S | 6 | 2/4/6 | 24 | 2.58 | `#ffd34d` |
| 磷 | P | 5 | 3/5 | 24 | 2.19 | `#ff9f43` |
| 氯 | Cl | 7 | 1 | 21 | 3.16 | `#34d399` |
| 钠 | Na | 1 | 0(离子) | 26 | 0.93 | `#a78bfa` |
| 溴 | Br | 7 | 1 | 23 | 2.96 | `#c026d3` |

### 3.2 成键规则

- **吸附判定**：原子 A 的空 slot 与原子 B 的空 slot 距离 < `snapR = 26 px` → 候选成键。
- **合法性**：`A.usedBonds < A.maxBonds` 且 `B.usedBonds < B.maxBonds`（离子键跳过，走电荷吸引）。
- **键角约束**：中心原子的 slot 按 VSEPR 分布——2 配位 = 180°（直线）、3 = 120°（平面三角）、4 = 109.5°（四面体）、含孤对则压缩（H₂O 实测 104.5°）。
- **吸附后的几何松弛**：成键后两原子沿 slot 方向各退 `bondLen = rA + rB + 16 px`，用 3 次迭代松弛解重叠（与 verlet 同模式，但非物理模拟，是**约束求解**）。
- **价态溢出**：若拖拽导致某原子超价，该键**闪红后弹回**，原子回到拖拽前位置（**不惩罚，只是不许**）。
- **电荷键**：`|ΔEN| > 1.7` 的原子对可走离子路径，跨距离成键（`ionicR = 60 px`），生成后显示 ± 角标。

### 3.3 判定与求解

- **分子拓扑比对**：把已成的键图规范化（Morgan 式：按度数分层做 canonical labeling），与 `target.canonical` 比较。规范化保证同分异构体不会被误判相等。
- **标准化输出**：`canonicalize(atoms, bonds)` 返回稳定字符串（原子按度数、元素符号、邻居度数排序）。校验器与运行时**必须用同一份实现**（放 `js/bond-forge-molecules.js`，两边 import）。
- **最优拖拽序列模拟**：`solveBest(level)` 用 BFS 在「拖拽状态空间」上搜索（状态 = 每个原子的位置槽位），返回最少拖拽次数。20 关的搜索空间经剪枝后 < 50k 状态，离线跑得动。

## 4. 样式设计

- **舞台**：520×680 逻辑坐标（比垂丝引露略宽，给原子盘留横向空间），全 Canvas 程序绘制、零贴图。
- **美术基调**：深靛底 + 网格「实验台」质感 + 顶部冷光。原子是**发光球体**（径向渐变 + 高光点），键是**哑光线**——发光与哑光对比让结构一眼可读。
- **色板**：H `#e8ecff` · C `#4a5568` · N `#5b8dee` · O `#ff6b7a` · S `#ffd34d` · P `#ff9f43` · Cl `#34d399` · Na `#a78bfa` · Br `#c026d3`；键线 `#ffffff @ 0.35`；成键成功脉冲 `#40d8ff`。
  > CSS 里凡命中 11 个映射值一律 `var(--tok-*)`（`p3-token-swap` 扫 `css/`）；canvas 绘制层 JS 字面量不属扫描域。
- **原子盘**：底部横向条（移动端）/ 左侧竖列（桌面），元素按族分组配色，拖出即复制。
- **UI 骨架**：`game-topbar` 中槽 = 关名 + 目标分子式 + 拖拽 HUD；桌面 `.game-sidebar` 三卡（本关 / 每日 / 榜单）+ 一张**「元素小抄」**卡（列出当前关出现的元素的价态，可折叠）；移动端换 `game-drawer`；`themeColor #0d1024`。
- **音效**：成键按**和声音程**——单键纯五度、双键大三度、三键小三度（听觉上「键越多越紧张」）；成键成功一记水晶音；非法键一记短促木质闷响（**不刺耳**）；目标分子完成时整段和弦收束。
- **动效**：吸附时 slot 收缩、键线从虚线 120ms 实化、成键瞬间沿键扩散一轮电子云脉冲、非法键红色抖动 3 次（±4px）。
- **按钮**：全部 `ICONS.*` + `game-btn`，零 emoji 按钮；原子盘的元素卡片允许显示元素符号（文字，非 emoji）。

## 7. 风险与规避

| 风险 | 规避 |
| --- | --- |
| **化学事实错误** | 所有分子进 `MOLECULES` 白名单并附中文名与 CAS-like 校验；键角数值硬编码自 VSEPR 表，不凭记忆写 |
| **同分异构误判** | 用 canonical labeling 比对拓扑，**不比字符串**；isomers 字段列全并显式提示 |
| **教育性变说教** | §2.6 反馈诚实原则：不扣分、不嘲讽、不说「不可能」；错误反馈永远附带规则本身 |
| **判定过严导致挫败** | 吸附半径 `snapR = 26` 偏宽容（宁可多吸附也不让玩家「明明贴上了却没连上」）；非法键只弹回不惩罚 |
| **`solveBest` 爆炸** | 状态空间剪枝：只考虑「与已有原子相邻的槽位」+ 对称性去重；单关上限 50k 状态，超限则该关 par 手工复核 |
| **移动端性能** | 单 canvas；原子数上限 12；辉光用径向渐变而非大面积 shadowBlur |
| **画面糊（后端缓冲区 < CSS 盒）** | `resize()` 用 `clientWidth`（整数）而非 `getBoundingClientRect().width`（亚像素），并监听 `game-frame:changed` —— 垂丝引露实测踩过此坑 |
| **抠类名错位导致样式静默失效** | JS 生成的 class 必须与 CSS 选择器逐字一致（垂丝引露踩过 `sd-chip` vs `sd-level-chip`） |
| **组件跨亮暗背景继承文字色** | 颜色显式声明，不用 `inherit`（垂丝引露 fg-audit 踩过） |
| **dist 诊断失明** | terser `drop_console` ⇒ 校验器一律 DOM/窗口探针断言 |
| **抽屉暂停差异** | 供 `pauseQuiet/resumeQuiet/isRunning` 三元组闭包 |
| **顶栏语言钮双绑** | 页面**不**给 `[data-chrome="lang"]` 挂 handler，点击归 chrome（垂丝引露踩过，一次点击切两次 = 净效果为零） |

## 8. 待拍板

1. **难度定位**：面向中学生（价键 + 官能团 + 键角，20 关）还是面向化学爱好者（加入立体化学、手性、共振式）？
   - 默认：**中学生**。手性/共振留到「进阶关」可选包，本期不做。
2. **是否做「反应式配平」模式**：给反应物与产物，玩家配系数。教育价值高但玩法偏 quiz，与本作「手感」定位不符。
   - 默认：**不做**，留 backlog。
3. **元素小抄卡是否常驻**：常驻会降低记忆训练价值，但能减少挫败。
   - 默认：**默认展开，可折叠**，且首次通关后自动收起。
4. **是否加「自由搭建」沙盒**：无目标，随便拼，只显示分子名。
   - 默认：**加**（低成本、高传播性、零关卡设计成本），作为开始菜单第三个瓦片。
5. `dailyTtlDays`：0（永久，同折光/弹弓/垂丝引露）还是 14（同电路）。
   - 默认：**0**。
