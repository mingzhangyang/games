# 新游戏创意建议

> 状态：**后续创意方案（已评审修订）** · 2026-09-26  
> 范围：基于当前 `games` 项目已实现的 23 款游戏，提出下一批可落地的新游戏方向。  
> 修订说明：初稿偏重视觉定位，评审后补充了每款游戏的「啊哈时刻」、失败张力、关卡示例和计分口径，并重做了三款主推游戏中两款的核心玩法（影织改为 2.5D 视差拼影，磁极花园改为格子化推拉）、为萤火信号加入同步玩法。评审结论见 §9。

## 1. 当前项目基线

当前 `main` 分支的游戏登记表（`games.config.json`）包含 23 款游戏，已经形成四条路线：

| 路线 | 代表作品 | 已覆盖体验 |
| --- | --- | --- |
| 传统街机与棋盘 | 俄罗斯方块、坦克大战、投篮、五子棋、黑白棋、扫雷 | 熟悉的规则、即时反馈、竞技和排行榜 |
| 物理系统谜题 | 引力弹弓、折光、电路谜题、垂丝引露、涟漪双生 | 轨迹、光线、电流、绳索和波纹交互 |
| 现代科学展柜 | 键合工坊、回声洞窟、麦克斯韦妖、晶绽、焰语 | 通过游戏理解化学、声学、热力学、晶体和光谱 |
| 清新自然 | 拔萝卜 | 节奏按压、连击、可爱卡通 |

两个需要正视的现状：

- **节奏玩法已被《拔萝卜》覆盖。** 新作不应再以「节奏」作为差异化卖点。
- **「20 关手工谜题 + 每日挑战」模板已经有 10 款左右。** 物理谜题和科学展柜几乎全部沿用这个模板，而真正带来高频重玩和排行榜活跃的是《投篮》《星球合成》这类无尽刷分玩法。下一批至少要有一款支持无尽刷分。

下一批游戏适合补足**空间投影、记忆与群体行为、离散推理**，避免继续重复光束、波纹、绳索、轨道、分子连线，以及「质点在布置好的力场中飞行」这一类机制（《引力弹弓》已占据）。

## 2. 推荐原则

- 每款游戏突出一个主要动作，让玩家在几秒内理解需要观察、移动、点击或调整什么。
- **每款游戏在设计阶段就要写清楚四件事**：啊哈时刻（玩家「看懂了」的瞬间）、失败张力（输从哪里来）、至少两个具体关卡示例、每日挑战与排行榜的计分口径。缺任何一项都不进入原型。
- 结果必须确定性可复现：同样的操作得到同样的结果，避免初值敏感的连续物理让解谜变成碰运气。
- 继续使用统一顶栏、HUD、统计抽屉和规则侧栏，但让每款游戏拥有独立的场景材质、角色和主题色。
- 优先采用竖屏舞台，核心交互区建议使用 480×640 或 560×640 的比例，操作区固定在画布下方。
- 触控目标保持至少 44px。颜色提示需要配合图案、形状或文字，避免只依赖颜色。

## 3. 优先推荐

| 游戏 | 核心体验 | 视觉方向 | 实现难度 | 模式 |
| --- | --- | --- | --- | --- |
| 影织 Shadow Loom | 移动光源，让不同深度的剪纸投影拼成目标剪影 | 剪纸剧场和靛蓝琥珀光 | 低至中 | 20 关 + 每日 |
| 磁极花园 Magnetic Garden | 在网格上摆放、翻转磁石，一格一格推拉种子入盆 | 可爱植物实验室 | 中 | 20 关 + 每日 |
| 萤火信号 Firefly Signal | 轻点萤火虫调整节拍，让整片虫群同步闪烁 | 夜晚草地和星座图案 | 低至中 | 关卡 + **无尽刷分** + 每日 |

影织承担视觉旗舰，磁极花园提供严谨的离散谜题，萤火信号提供短局、无尽刷分和每日挑战，同时把真实的萤火虫同步现象接入科学展柜路线。

### 3.1 影织 Shadow Loom

**一句话定位**：在小型纸剧场里移动光源，让不同深度的剪纸投影拼成一个完整的剪影。

**为什么要改初稿的做法**

初稿设想「单光源 + 二维几何 + 挡板旋转」。在二维里，点光源把一块纸片投到墙上只会整体缩放和平移，谜题会退化成「挪光源，直到大小对上」，没有空间上的惊喜。Shadowmatic 类游戏的乐趣来自「换一个角度，突然认出剪影」，所以需要引入深度。

**核心玩法（2.5D 视差）**

舞台上有 2～5 张剪纸，分别固定在不同深度（离墙近的投影小而清晰，离光源近的投影大而偏移明显）。玩家拖动光源（后期可旋转部分剪纸），每张剪纸的投影以不同比例移动和缩放，玩家要让它们在墙上拼成目标剪影。

- 投影计算：点光源 `L`、剪纸深度 `d`、墙面深度 `W`，投影点 `P' = L + (P − L) × (W − L.z) / (d − L.z)`。纯二维计算，不需要物理引擎。
- 判定：把当前投影和目标剪影分别画到离屏画布，按像素交并比（IoU）判定，达到阈值（如 0.92）过关。
- 啊哈时刻：零散的纸片在某个光源位置突然「合成」一只兔子；过关后剪影活过来（兔子跳走、鸟飞出画面）。
- 失败张力：光源移动次数有限（按关卡给出星级阈值）；后期加入「必须留在光区外」的剪纸，防止无脑扫遍全场。

**关卡示例**

1. 两张剪纸：兔身（近墙）+ 兔耳（近光源），光源平移即可让耳朵落到头顶。教学关，1 星阈值宽松。
2. 三张剪纸：鸟身、左翼、右翼分处三个深度，光源需要同时满足水平与垂直两个方向的对齐，只有一个正确区域。
3. 后期：双光源，两个剪影必须同时成立；或引入半透明薄纸（投影叠加区颜色加深，目标要求特定重叠区域）。

**计分口径**：每关按光源拖动次数 + 最终 IoU 给 1～3 星；每日挑战为 5 关种子关卡，排行榜记录总拖动次数（`asc`）。

**美术方向**

使用剪纸边缘、纸张层次、木质舞台和局部光晕。靛蓝背景承接现有深色界面，琥珀色投影负责关键反馈。目标轮廓用虚线、网点和轮廓线表达，保证色觉差异下仍然清晰。

**项目适配**：与《折光》的区别是解决投影轮廓和深度视差，而不是寻找光束路径。SVG 或 canvas 均可，IoU 用低分辨率离屏画布（如 120×160）计算即可满足性能。

**实现难度**：低至中。

### 3.2 磁极花园 Magnetic Garden

**一句话定位**：在网格花圃里摆放和翻转磁石，一格一格地推拉带磁性的种子，把它们送进花盆。

**为什么要改初稿的做法**

初稿设想「拖动磁石，种子在吸引/排斥场中连续运动」。这和《引力弹弓》的核心手感几乎一样——质点在布置好的平方反比场中走出弯曲轨迹；而且连续物理对初值敏感，玩家容易觉得是运气而不是推理，20 关的关卡设计也难以保证唯一且可读的解。

**核心玩法（离散推拉）**

花圃是 7×9 左右的网格。玩家每回合做一件事：放置一块磁石、移动一块磁石或翻转一块磁石的极性。操作后，所有带磁种子按固定规则同步结算：

- 同一行或列上、视线无遮挡的最近磁石作用于种子：异极相吸，种子向磁石滑动直到被阻挡；同极相斥，种子背离磁石滑动直到被阻挡。
- 铁门、石块、其他种子都会阻挡滑动；种子停在花盆格即入盆。
- 结算完全确定，可以提供「撤销」和「重来」，没有任何随机性。

啊哈时刻：发现一次翻转极性能让两颗种子朝相反方向同时就位；或利用一颗已停下的种子当作另一颗种子的「挡板」。

失败张力：每关限定磁石数量与总步数；种子滑出花圃边界会枯萎，需要撤销。

**关卡示例**

1. 一颗 N 极种子、一个花盆在它右侧 3 格：在花盆右边放一块 S 极磁石，种子被吸过去停在花盆。教学关。
2. 两颗种子在同一行、两个花盆在上下两侧：先吸一颗停到障碍后，再翻转极性把另一颗推出去，考察结算顺序。
3. 后期：固定磁块（不可移动）、磁屏蔽墙、需要同时引导三颗种子且步数恰好够用。

**计分口径**：按步数给星；每日挑战为种子生成的关卡（生成器用 BFS 验证可解并给出最优步数作为 par，思路同《引力弹弓》每日球场），排行榜记录超出 par 的总步数（`asc`）。

**美术方向**

场景是一个可爱的植物实验室。磁石设计成带表情的园艺工具，种子会长出小脚或叶片。背景使用薄荷绿、奶油白和珊瑚红，南北极通过 N / S 标记、箭头和磁力线共同表达（不只靠红蓝颜色区分）。滑动动画可以做得弹性、可爱，但逻辑是格子。

**项目适配**：与《引力弹弓》《垂丝引露》彻底拉开——没有发射，没有连续轨迹，是推箱子式的离散推理。规则侧栏能自然解释「同极相斥、异极相吸」。

**实现难度**：中。难点在关卡设计与每日生成器的可解性验证，渲染和规则本身简单。

### 3.3 萤火信号 Firefly Signal

**一句话定位**：夜里的萤火虫各闪各的，玩家轻点它们调整节拍，让整片虫群同步亮起。

**为什么要改初稿的做法**

初稿是「观察闪烁顺序，再点击复现」，本质上是经典的 Simon 记忆游戏：玩法成熟、上限低，每日挑战的吸引力也弱；而「节奏」卖点已被《拔萝卜》覆盖。萤火虫同步闪烁本身是真实的自然现象（耦合振子同步），把它做成玩法更原创，也能接入科学展柜路线。

**核心玩法（群体同步）**

每只萤火虫有自己的闪烁周期和相位（一个在圆周上转动的「时钟」）。邻近的萤火虫会互相轻微拉拢相位（简化的耦合规则）。玩家轻点一只萤火虫，会让它立刻闪一次、相位归零，并通过耦合带动附近的同伴。

- 目标：在限定时间内让全部（或指定比例）萤火虫同步闪烁，同步度以 0～100% 的光环实时显示。
- 干扰：固执虫（耦合弱、需要多次点击）、急性虫（周期更短）、灯笼等假光源（会把附近虫群带偏）。
- 啊哈时刻：点对了几只「枢纽」萤火虫后，整片草地在一两拍内连锁同步，一起亮起。
- 失败张力：点击次数有限；点得太急会打乱已经同步的群体。

**模式**

- **关卡**：萤火虫布局逐步复杂（稀疏群、两个分离群靠一只桥接虫、带灯笼干扰）。
- **无尽刷分**：萤火虫不断飞入草地，玩家维持同步度，同步度越高、持续越久得分越高，同步度跌破阈值即结束。这是本批次承担高频重玩和排行榜活跃度的作品（`desc`）。
- **每日**：种子生成布局，排行榜记录达成全同步的点击次数（`asc`）。
- **可选的记忆变体**：同步完成后，萤火虫按顺序点亮并连成一个星座，玩家复现连线可获得额外星星——保留初稿的记忆元素，但作为奖励环节，而不是主玩法。

**美术方向**

夜晚草地、芦苇、露珠和远处的星座构成主要场景。深蓝、金黄和薄荷绿形成清楚的层次。同步度除了光环数值，还用萤火虫的外轮廓（同步的萤火虫带同心圆描边）表达。声音只作为增强反馈，不是完成关卡的必要条件；`prefers-reduced-motion` 下关闭拖尾和闪烁光晕，只保留亮度变化。

**项目适配**：适合手机单手操作，可做短局。规则侧栏可以用一句话介绍真实现象（东南亚萤火虫的同步闪烁）。

**实现难度**：低至中。核心是 N 个相位振子的简化耦合（N ≤ 60，每帧 O(N·k) 邻居更新），难点在于调参让同步「可控但不自动」。

## 4. 其他可选方向

| 游戏 | 核心玩法 | 美术方向 | 评审意见 |
| --- | --- | --- | --- |
| 化石层语 Fossil Strata | 根据线索排列地层、旋转碎片并拼出化石 | 岩层剖面、琥珀和考古工作台 | **最有差异化的备选**：推理为主、不计时、节奏安静；风险是每关都要绘制素材，内容成本高 |
| 潮汐守望 Tidekeeper | 调整闸门和水道，在潮水涨满前把水引入潮池并救出小生物 | 海玻璃、潮池、螃蟹和小章鱼 | 水流模拟成本高；分流路径逻辑与《电路谜题》接近，需先找到独有机制 |
| 光合工坊 Photosynthesis Lab | 平衡阳光、水和二氧化碳，让植物长成指定形态 | 透明温室、植物剖面和可爱苗圃 | **趣味风险最大**：调滑块看结果容易变成缺乏挑战的「玩具」，手感与《晶绽》的曲线调节类似 |
| 云端邮差 Cloud Courier | 调整风向和气流，把纸飞机送到目标云岛 | 彩色天空、云朵角色和邮票元素 | 用场引导飞行物，与《引力弹弓》、《垂丝引露》的微风机制重叠，不建议推进 |

### 4.1 化石层语 Fossil Strata

玩家通过颜色、颗粒、断层和化石碎片判断地层顺序，再旋转碎片完成化石复原。它是一款线索推理和形状拼合游戏，节奏较慢，适合为项目增加不依赖计时和连击的体验。为控制内容成本，可以让地层用程序生成（颜色 + 纹理 + 化石类型组合），只有化石本身手绘。

### 4.2 潮汐守望 Tidekeeper

把水位、闸门和潮汐倒计时组合成关卡，每个小生物都有明确的栖息水位。推进前需要回答：它和《电路谜题》的「开关 + 分流」有什么本质区别？一个可能的方向是「水位随时间上涨」带来的实时压力，但这会显著提高实现难度。

### 4.3 光合工坊 Photosynthesis Lab

把阳光、水和二氧化碳做成可调整的资源，玩家在一天的时间窗口内把植物培养到指定形态。推进前需要补充失败张力（资源互相制约？天气事件？），否则只是一个可以把玩的模拟器。

### 4.4 云端邮差 Cloud Courier

玩家调整几个风场节点，让纸飞机沿气流滑行到目标云岛。机制与《引力弹弓》和磁极花园初稿同类，暂不推进；纸飞机、云朵和邮戳的叙事元素可以留给其他作品。

## 5. 系列化方向

《拔萝卜》是清新自然路线的起点，但后续作品不必全部采用相同的卡通农场场景。建议把自然主题分成两种气质，并继续使用统一的产品外壳。

| 路线 | 代表作品 | 设计语言 |
| --- | --- | --- |
| 自然图鉴 | 萤火信号、化石层语、潮汐守望 | 观察、保护、发现，画面更柔和，信息量更低 |
| 自然实验室 | 磁极花园、光合工坊、晶绽 | 操作、调节、验证，保留实验台和数据读数 |

两条路线可以交替发布。这样既不会让项目长期停留在单一的科学实验视觉，也不会因为连续推出可爱花园游戏而削弱现有科学展柜的辨识度。

## 6. 实施顺序

| 阶段 | 建议作品 | 主要目标 | 原因 |
| --- | --- | --- | --- |
| 第一阶段 | 影织（2.5D 视差） | 建立新的视觉旗舰和空间谜题模板 | 美术辨识度高，视差机制原创且技术风险可控 |
| 第一阶段 | 萤火信号（同步） | 补充短局、无尽刷分和每日挑战 | 开发量小，同时解决「缺少无尽刷分」的组合缺口 |
| 第二阶段 | 磁极花园（格子推拉） | 拓展离散推理和自然实验室路线 | 规则确定、关卡可验证，与现有物理谜题拉开距离 |
| 第三阶段 | 化石层语 | 增加不计时的安静推理 | 差异化最强，内容成本可通过程序生成地层缓解 |

潮汐守望和光合工坊需要先补齐失败张力与独有机制，再决定是否进入排期。

## 7. 共同落地约束

- **登记与代码生成**：新游戏先在 `games.config.json` 登记，再 `npm run gen`；不要手改 sitemap、Worker `GAMES` 映射等派生文件（见 `docs/contracts/registry.md`）。
- **caps**：参照现有谜题游戏，默认带 `sidebar`、`drawer`、`frame-budget`、`topbar`、`analytics`；有排行榜和每日时加 `leaderboard`、`daily`；自然路线的浅色画面适合同时支持 `theme-light`（见 `docs/contracts/theme.md`）。
- **排行榜键名**：总榜 `<id>`，每日榜 `<id>-d<YYYYMMDD>`，由共享 `game-scores` Worker 按 `scores` 块处理；关卡类记录步数用 `asc`，萤火信号无尽模式用 `desc`。
- **共享模块**：日期与种子只用 `js/daily.js`，存储只用 `js/safe-storage.js`，页面启动用 `js/boot.js` 的 `onReady`，界面外壳用 `bindChrome` / `createStatsDrawer` / `bindFrame`。
- 优先制作 390×844 手机视口的完整布局，保证舞台和底部操作区都能充分利用高度且不发生页面溢出。
- 操作按钮保持至少 44px，触控输入放在画布下方，避免画布内悬浮按钮遮挡核心场景。
- 所有关键状态都用颜色加图案、轮廓、线型或文字表达，并提供 `prefers-reduced-motion` 支持。
- 每款游戏先完成一个可玩的核心循环（含 §2 要求的四件事），再扩展关卡、排行榜、每日挑战和更复杂的场景动画。

## 8. 下一步建议

下一款最适合先做《影织》的视差原型：只需 3 个关卡，验证「移动光源 → 纸片合成剪影」的啊哈时刻是否成立，以及 IoU 阈值的手感。同时可以用很小的成本做《萤火信号》的耦合原型，重点调出「可控但不自动同步」的参数区间。

如果视差原型的啊哈感不足，退路是改为少量低多边形立体物件旋转（更接近 Shadowmatic），但实现难度会升到中高，需要重新评估排期。
