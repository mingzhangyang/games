# 折光 Lumen：难度与趣味性重做（2026-10）

## 1. 问题：为什么「每一关都太简单」

旧版 25 关有三个共同点：

1. **盘面上每面镜都是答案的一部分**（2–6 面镜，几乎全部要翻），不存在「选哪条路」。
2. **水晶沿答案光路摆放**，水晶本身就把路线画出来了。
3. **每面镜独立、反馈即时**：翻对一面，亮的水晶立刻变多。

量化：用一个「哪面镜让亮的水晶变多就点哪面」的贪心机器人去打，旧版 **25 关全部以 par 步通关**
（3★ 率 100%）。玩家完全不需要规划，只需要跟着光走。

## 2. 改法

### 2.1 新元件（`src/games/lumen/model/beam.js`）

| 元件 | 规则 | 破掉的是哪种「无脑解」 |
| --- | --- | --- |
| 诱饵镜 | 盘面上的镜子比答案多；它们放在路径镜「翻错时」的去向上 | 「每面镜都要翻」 |
| 暗晶 `x` | 光可以穿过，但被照到就不算过关 | 「最近的那条路就是答案」——最显眼的路线会照到暗晶 |
| 联动镜 | 同色光环的镜面点任意一面，整组一起翻 | 「每面镜独立」——修好这面会弄坏那面 |
| 分光镜 | 金色玻璃片：光既按镜面反射、又直行穿过 | 「一条光路」——每条支路都要避开暗晶 |

分光镜和联动组是镜面的附加属性（挂在关卡对象的 `split` / `links` 上），字符网格仍然只表达朝向，
所以点击翻转、轨迹追踪和旧的反射表都没变。所有光束共享 `(格, 方向)` 访问表，分光镜回环也必然终止。

### 2.2 用解空间指标定义「难」（`src/games/lumen/model/solver.js`）

一次点击翻转一个「单元」（联动组整组或单面镜），盘面 = 相对解态的单元位掩码，
所以最少点击数 = 汉明距离，与点击顺序无关。单元 ≤ 12，2^u 全枚举后：

- **par**：初盘到最近可解态的真·最少点击数；**最优解唯一**（nearest = 1）。
- **预见步数（foresight）**：沿最优解的所有点击顺序里，至少有几步点完「亮水晶 − 亮暗晶」不增。
  0 = 跟着光走就能解（旧版每一关）；≥ 1 = 必须先想清楚再点。
- **贪心 3★ 率**：贪心机器人（每步点进度最高的单元，平局随机、不立刻撤销）par 步内通关的比例。
- **闲置单元**：在初盘、解态或一步之遥时都碰不到光的镜面——不允许存在。

### 2.3 关卡：5 章 × 5 关，锯齿形难度

| 章 | 机制 | 设计 |
| --- | --- | --- |
| 1 折光 | 诱饵镜、墙 | 1-1 / 1-2 教学，之后加码到预见 3 |
| 2 暗晶 | + 暗晶 | 首关教学（初盘就有一颗被照红） |
| 3 联动 | + 联动镜 | 首关两组都「顺手」，之后要拆开取舍 |
| 4 分光 | + 分光镜、暗晶 | 分出来的支路必须点亮水晶 |
| 5 万象 | 双光束 + 全部元件 | 终章 |

每章首关在开局弹一条机制介绍；侧栏「玩法说明」带四种元件的图例。
星级：≤ par 三星，≤ par + 2 两星（旧版是 par + 3），其余一星——不限步数，总能通关，星星奖励规划。

关卡由 `tools/generators/lumen-levels.mjs` 出候选：沿发射器「长」出一条光路，在每面路径镜翻错的去向上放诱饵，
再贪心地挑最能排除其他状态的水晶 / 暗晶，最后在所有初盘里挑最难的那个。人工按指标分档挑选、看图后写进
`model/levels.js`，发布后与生成器解耦。

设计时测得（`node tests/verify-lumen-levels.mjs` 会打印这张表）：非教学关贪心 3★ 平均率 **9%**（旧版 100%），
每章末关预见 ≥ 3，终章 par 5–6。

### 2.4 每日谜题

24 个双光束布局（含暗晶 / 联动 / 分光），种子 = FNV-1a(`'lumen-' + UTC+8 日期`)，
布局 = 种子 % 24，初盘 = `solver.scramble(mulberry32(种子))`：保证 par ∈ [4,6]、最优解唯一、预见 ≥ 2。
旧版每日的 par 只是「打乱了几面镜」，不一定是真最少点击数；现在是。上线当天的每日题会换成新题。

## 3. 存储

星级改为按关卡 id 存（`game:lumen:v2:stars = { 'refract-1': 3, … }`）。旧版按下标存的星级对应的关卡已全部替换，
迁移成空对象；`lm_stars` / v1 键原样保留不删。每日的 `lm_daily_*` / `lm_local_*` 协议键不变。

## 4. 锁定

- `tests/verify-lumen-levels.mjs`（离线）：par = 独立 BFS 最少点击数、最优解唯一、无闲置镜面、
  各章机制在场、每颗暗晶有戏份；难度下限（教学关外预见 ≥ 1 且贪心 3★ ≤ 50%，
  章内第 2 关起预见 ≥ 2 且 ≤ 15%，章末关预见 ≥ 3，平均 ≤ 12%）；每日 730 天全扫描。
  反向验证：同一套难度断言跑旧版 25 关，23 个非教学关全部不达标。
- `tests/smoke-lumen.mjs`（浏览器）：暗晶照红的像素、联动组真实点击整组翻转、5-5 按最优解真实点击三星通关。
- 调关卡后重跑 `node tests/verify-lumen-levels.mjs`；换关用生成器出候选，不要手改 spec 而不过校验器。
